# Docs

Supporting media for the project.

- **`images/`** — board photos (top/bottom, assembled, in enclosure), heater in operation, any renders. Referenced from the root `README.md` gallery section.

Suggested shots to include, since this is going in a CV/portfolio:

1. Assembled PCB, top-down, well-lit, in focus (the "hero" shot).
2. PCB populated but before final assembly (shows soldering quality).
3. The heater + thermistor assembly connected to the board.
4. The board running, e.g. LED lit for an active stage.
5. A short clip or GIF of the button press → LED stage cycling → temperature rising (optional, but effective for a portfolio piece).
6. Any 3D render of the PCB from your CAD/EDA tool, if you have one — these often look cleaner than photos for a first impression.
